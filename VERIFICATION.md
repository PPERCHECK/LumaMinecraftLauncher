# Проверка Luma 0.1.0

Проверено на Windows x64. Сборка TypeScript/Vite и упаковка electron-builder завершились успешно.

- 13 модульных тестов: UUID Minecraft, защита путей и ZIP, запрет symlink, сохранение исходного файла при неверной сумме, кэширование, HTTPS, повтор после ECONNRESET, последовательность и отмена очереди, аргументы запуска, адреса серверов и настоящий TCP status ping с фрагментацией пакета.
- 13 smoke-проверок: запуск приложения, актуальный манифест Mojang с историческими версиями, живой Modrinth, явная ошибка отсутствующего ключа CurseForge, метаданные Fabric/Quilt/Forge/NeoForge, локальный профиль, изоляция сборки, backup/restore миров и параметров, темы, DPAPI, IPC, автоматическая установка Java 17 и всей Minecraft 1.20.1, отсутствие необработанных ошибок renderer.
- 9 runtime-проверок: реальный запуск Vanilla 1.20.1, создание Fabric-сборки, установка Sodium Extra с Sodium и Fabric API из Modrinth, выключение мода без удаления данных, установка Fabric 0.20.1, реальный запуск Fabric с модами, экспорт mrpack без встраивания jar, повторный импорт mrpack по настоящим URL/хешам, редактирование конфигурации и восстановление пресета.
- Готовый `Luma Launcher.exe` отдельно запущен из `release/win-unpacked`; интерфейс и IPC работают, версия 0.1.0, пользовательские аккаунты и сборки в поставке отсутствуют.
- Production dependency audit после обновления adm-zip и undici: 0 vulnerabilities на момент проверки.

Minecraft действительно загружала ресурсы и создавала графические атласы; тест проверял, что процесс продолжал работать после запуска. Прохождение одиночного мира, подключение к публичным серверам и все сочетания загрузчиков/версий не проверялись.

Microsoft/Ely.by OAuth с пользовательскими аккаунтами и CurseForge с действительным ключом не проверены сквозным сценарием. Forge, Quilt и NeoForge проверены на получение метаданных, но не на полный игровой запуск. Alpha/Beta доступны из манифеста, но их игровой запуск не проверен. Эти ограничения не подменяются заглушками.

Визуально осмотрены главная и переход к каталогу. Дальнейшее управление окном было остановлено пользователем клавишей Esc; последующие проверки выполнены программно без управления рабочим столом.

Сценарии воспроизводятся командами из README. Тестовые сборки, игровые файлы, токены и кэши не включены в архив исходников или приложения.
