# Luma Launcher

**Версия 0.3.0:** Windows Setup, автообновления через GitHub Releases, фотогалерея, мастер первого запуска, новые ссылки на каталоги и экспериментальный раздел Horizon. Установка: `Luma-Setup-0.3.0.exe`. Подробности — [RELEASE.md](RELEASE.md).

Десктопный лаунчер Minecraft Java Edition для Windows x64. Electron + React + TypeScript, собственное оформление и изолированные игровые сборки.

## Запуск готового приложения

1. Запустите `Luma-Setup-0.3.0.exe` и выберите папку установки.
2. При первом запуске выберите Microsoft, Ely.by или локальный профиль, настройте оформление и создайте первую сборку. Вход через Microsoft и Ely.by требует собственных OAuth-данных.
3. Выберите версию Minecraft и загрузчик.
5. Нажмите «Играть». При первой установке Luma скачает подходящую Java, игру, библиотеки и ресурсы. Прогресс находится в «Загрузках».

Node.js и заранее установленная Java для готового приложения не нужны. Интернет нужен для первоначальной установки, каталогов и обновления сетевых сессий. После установки локальная Vanilla-сборка использует скачанные файлы. Версионный манифест кэшируется на 15 минут с возвратом к сохранённой копии при сетевой ошибке.

## Сборка из исходников

Нужны Windows 10/11 x64, Node.js 22+ и npm. Команды выполняются в папке с `package.json`:

```powershell
npm ci
npm run dev
```

Готовая локальная сборка и запуск:

```powershell
npm run build
npm start
```

Упаковка Windows-приложения:

```powershell
npm run pack
```

Результат: `release/win-unpacked/Luma Launcher.exe` вместе с файлами Electron. Для переноса архивируйте всю папку `win-unpacked`. Сертификат подписи не включён. Автообновления работают в установленной Setup-версии.

Проверки:

```powershell
npm test
npm run check
npm run test:smoke
node scripts/smoke.mjs --install
npm audit --omit=dev
```

Smoke-тесты используют отдельную папку `../smoke-data`, тестовый локальный профиль `LumaTest` и тестовые сборки. `--install` скачивает настоящую Minecraft 1.20.1 и Java 17, примерно 800 MB с библиотеками. Пользовательские данные приложения эти тесты не используют. Результат записывается в `../smoke-results.json`.

## Ключи и вход

**Modrinth:** ключ не нужен. Каталог доступен сразу через публичный API v2. Каждый запрос содержит User-Agent; ошибки сети, HTTP 429 и другие ограничения выводятся пользователю.

**Microsoft:** в «Настройки → Интеграции» введите собственный Application (client) ID приложения Microsoft Entra, зарегистрированного для личных Microsoft-аккаунтов. Включите public client flow для device code. Приложению также нужен доступ к Minecraft Services; его отсутствие может приводить к HTTP 403. Client Secret не нужен и не используется. Пароль вводится только на странице Microsoft в браузере. После OAuth выполняется цепочка Xbox Live → XSTS → Minecraft Services, проверка entitlements и получение профиля со скином. Сессия обновляется перед запуском.

**Ely.by:** зарегистрируйте Website OAuth-приложение. Введите собственные Client ID, Client Secret и точный Redirect URI, например `http://localhost:38479/callback`. URI должен совпадать с зарегистрированным. Используются scopes `account_info minecraft_server_session offline_access`, проверка OAuth state и обновление токена. Скины и игровые сессии подключаются через скачиваемый с проверкой SHA-256 authlib-injector. Для персональной установки секрет хранится локально под защитой ОС. Для публичного продукта с общим Client Secret нужен собственный доверенный сервер обмена токенов: в десктопной поставке общий секрет защитить от владельца устройства нельзя.

**CurseForge:** получите свой API key в CurseForge for Studios и сохраните в «Настройки → Интеграции». Учитываются запрет `allowModDistribution=false` и отсутствие `downloadUrl`: в этих случаях автоматическое скачивание прекращается с предложением открыть страницу проекта. Обход ограничений или неофициальные зеркала не используются.

**По нику:** локальный UUID v3 по формуле Minecraft `OfflinePlayer:<ник>`, одиночная игра и серверы без обязательной проверки лицензии. Этот режим не предоставляет официальную лицензию и не открывает доступ к серверам с Microsoft-авторизацией. Ely.by также не заменяет Microsoft на таких серверах.

Встроенных ключей и чужих Client ID нет. Секреты не попадают в исходники, `state.json`, настройки, видимые renderer-процессу, или экспорт оформления. На Windows они хранятся в `vault.bin`, зашифрованном Electron safeStorage / Windows DPAPI. Это системная защита локального файла, а не запись в интерфейсе Credential Manager. Выход удаляет локальные токены; он не завершает браузерную сессию Microsoft/Ely.by.

## Что реализовано

- Главная с выбранной сборкой, профилем, версией и запуском; шесть цветных фотографий для обложек и фона. Источники — [PHOTO_CREDITS.md](PHOTO_CREDITS.md).
- Мастер первого запуска: способ входа, оформление, первая сборка; для Microsoft-профиля ссылка на официальный установщик Bedrock Edition.
- Экспериментальный раздел Horizon: актуальный релиз официального Windows-лаунчера с GitHub, загрузка в очередь с проверкой SHA-256. Установку и дальнейшие обновления Horizon выполняет его собственный лаунчер.
- Дополнительные внешние каталоги Feed The Beast, Planet Minecraft и Vanilla Tweaks. Встроенный импорт принимает .mrpack и CurseForge ZIP; файлы с других сайтов устанавливаются согласно их собственным инструкциям.
- Русский / английский интерфейс; светлая / тёмная темы; акцент, фон, размытие свечения, непрозрачность панелей, масштаб, плотность, свёрнутая панель и стартовый экран; отключение анимаций. Импорт темы с предварительным просмотром и экспорт без ключей.
- Несколько Microsoft, Ely.by и локальных профилей с быстрым переключением; официальные OAuth-потоки и обновление сессий.
- Динамический манифест Mojang: релизы, снапшоты, Alpha и Beta. Fabric / Quilt из официальных Meta API, Forge / NeoForge из Maven metadata. Список совместимых версий загрузчика выбирается до создания сборки.
- Установка Java из Eclipse Adoptium по требуемому major из Minecraft metadata с проверкой SHA-256; ручной выбор Java, RAM, JVM/game arguments и разрешение отдельно для каждой сборки.
- Установка игры и запуск через XMCL Core; собственный загрузчик ресурсов с SHA-1, ограниченным параллелизмом, повторными попытками и отменой. Общий кэш ресурсов и отдельные игровые папки.
- Modrinth и CurseForge: единый экран с выбором одного или обоих источников, поиск, тип проекта, версия игры, загрузчик, категории, популярность / обновление / новизна; описание, галерея, выбор версии проекта.
- Установка обязательных зависимостей; проверка объявленных ограничений Minecraft/loader и известных несовместимых зависимостей. Ручные .jar явно обозначаются как непроверенные. Полное выявление всех конфликтов не обещается.
- Импорт Modrinth `.mrpack` и CurseForge ZIP с `manifest.json`, безопасная обработка путей и overrides. Каталожный модпак создаётся как новая изолированная сборка.
- Экспорт `.mrpack` для файлов с URL и SHA-512 (без CurseForge) и CurseForge manifest ZIP для сборок из отслеживаемых CurseForge-файлов. Для смешанных или локальных сборок предусмотрена полная локальная резервная копия, без скрытого включения чужих .jar в публичный экспорт.
- Обновление отслеживаемых модов с копией перед изменениями; ручное добавление .jar; выключение через переименование `.disabled` без удаления.
- Раздел «Читы»: настоящий поиск клиентских модов, быстрые запросы X-Ray / ESP / Freecam / Fullbright / Automation, ручной импорт, независимые сборки, переключатели модов, редактор текстовых конфигураций, пресеты папки config и резервные копии. Это интерфейс управления внешними модами, сами читы в лаунчер не встроены. Присутствует предупреждение о правилах серверов и банах.
- Избранные серверы с настоящим Minecraft status ping, SRV-записями, игроками, версией и быстрым подключением.
- Очередь установки / обновлений / импорта с прогрессом, скоростью, отменой и повтором. Очередь хранится до закрытия приложения, а уже проверенные файлы повторно не скачиваются.
- Полные резервные копии, откат с сохранением текущего состояния, консоль и игровые логи, быстрые папки модов / миров / скриншотов / config; время игры.

## Ограничения первой версии

- Сквозной вход Microsoft/Ely.by, работа с пользовательскими лицензиями и CurseForge с действительным ключом требуют проверки на ваших аккаунтах. В комплекте нет доступа к этим аккаунтам.
- Получение версий всех загрузчиков проверяется отдельно от установки. Не каждая комбинация Minecraft, загрузчика, Java и модов прошла игровой тест. Для очень старых Alpha/Beta возможны проблемы старого LWJGL, графики и звука; доступность метаданных не равна гарантии работоспособности на современном ПК.
- Импорт существующей папки копирует её содержимое в изолированную сборку с указанными пользователем версией и загрузчиком. Автоматического распознавания произвольных сторонних launchers/custom version JSON нет.
- У импортированного `.mrpack` файлы сохраняют URL и контрольные суммы; в этой версии они не всегда привязаны к project/version ID Modrinth. Такие файлы не участвуют в автоматическом обновлении отдельных модов. Обновление исходного модпака выполняется импортом новой версии как отдельной сборки с возможностью сохранить старую.
- Устанавливаются обязательные зависимости, которые объявлены API. Необязательные предлагаются через каталог. Тонкие ограничения версий между модами, встроенные в jar, не анализируются полностью.
- В объединённом каталоге запросы к источникам выполняются отдельно; глобальные рейтинги и пагинация источников могут различаться. Галерея и описания отображаются безопасным текстом и изображениями; произвольный HTML не исполняется.
- Проверка серверов использует современный status protocol; очень старые серверы без него могут отображаться Offline.
- Непрозрачность относится к панелям приложения, а не к прозрачности окна рабочего стола. Редактор конфигов не пытается придумывать параметры, не описанные автором мода.
- Одновременно для одной сборки допускается одна изменяющая операция. Установку/обновление/восстановление модов нельзя выполнять при запущенной игре. При закрытии лаунчера активная очередь прекращается; статистика оставшейся запущенной игры после закрытия не записывается.

## Данные и резервные копии

Кнопка «Настройки → Основные → Открыть папку данных» показывает фактическое расположение. Структура:

```text
state.json              публичные настройки, профили, сборки и серверы
vault.bin               защищённые токены и API-ключи
minecraft/              общие versions, libraries и assets
java/                   автоматически установленные Java
instances/<UUID>/       mods, saves, screenshots, config, logs и options
backups/<UUID>/         полные ZIP-снимки игры и параметров сборки
presets/<UUID>/         пользовательские пресеты конфигураций
cache/                  скачанные архивы Java и модпаков
```

Резервные копии создаются до изменений модов, конфигов и отката. Они могут занимать много места. Не переносите `vault.bin` на другую учётную запись Windows: DPAPI привязывает шифрование к пользователю. Для переноса на другой компьютер скопируйте игровые данные и выполните вход заново.
