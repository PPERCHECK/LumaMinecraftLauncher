# Luma 0.5.0 — установка и обновления

## Установка

Запустите `Luma-Setup-0.5.0.exe` на Windows x64. Мастер предложит язык и папку установки. После установки откроется мастер первого запуска: выберите аккаунт, оформление и первую сборку. Microsoft и Ely.by требуют собственных OAuth-данных; локальный профиль подходит для одиночной игры и серверов без проверки официальной лицензии.

Обновление поверх прежней версии сохраняет `%APPDATA%\Luma Launcher`: аккаунты, миры и сборки. Удаление приложения тоже не удаляет игровые данные.

## Автообновление Luma

Источник — [GitHub Releases](https://github.com/PPERCHECK/LumaMinecraftLauncher/releases). Установленное приложение проверяет новую стабильную версию через 20 секунд после запуска и каждые 4 часа, загружает её в фоне и предлагает перезапуск. При запущенной игре или текущей загрузке установка откладывается. В «Настройки → О приложении» есть ручная проверка и переключатель автоматической проверки. Проверка SHA-512 подтверждает соответствие загруженного файла метаданным релиза. Установщик пока не подписан сертификатом издателя Windows.

Для обновлений GitHub Release должен содержать Setup EXE, `.exe.blockmap` и `latest.yml` из одной сборки. Следующий выпуск должен иметь новый номер версии; файлы уже опубликованной версии не заменяйте.

## Что добавлено в 0.5.0

- Тарифы Starter, Luma Connect (149 ₽/мес.) и Luma Cloud (249 ₽/мес.) с экраном преимуществ и QR-кодом оплаты.
- Локальная админ-панель владельца. Доступ генерируется при первом нажатии, пароль показывается один раз и хранится через системное защищённое хранилище Windows.
- Администратор получает Pro-возможности бесплатно на текущем компьютере и может заменить checkout-ссылку, из которой строится QR-код.
- Реальная проверка платежей намеренно не имитируется: для неё нужен backend, платёжный провайдер и webhook.

## Возможности 0.4.0

- Синхронизация языка Minecraft перед каждым запуском через штатный `options.txt`. Поддерживаются `ru_ru`, `en_us`, `uk_ua`, `de_de`, `fr_fr`, `es_es`, `pl_pl`, `pt_br` и `zh_cn`.
- Девять языков в настройках интерфейса. Ключевые разделы имеют переводы, остальные строки используют английский запасной вариант.
- Раздел «Друзья» с локальным списком адресов и прямым подключением к выбранной сборке.
- Поиск обычных открытых миров Minecraft через LAN multicast.
- «Открыть для сети»: установка Auto LAN и зависимостей с Modrinth, затем запуск совместимой Fabric/Quilt-сборки. Мир публикуется после его загрузки в Minecraft.

Локальная игра работает внутри одной сети. Брандмауэр Windows должен разрешать Java/Minecraft принимать подключения. Luma не содержит центрального сервера друзей, не пробивает NAT и не превращает LAN в интернет-сервис. Для друзей из другой сети используйте доверенную VPN или отдельный туннель.

## Возможности 0.3.0

- Шесть локально включённых цветных фотографий для обложек сборок и фона. Источники и лицензия перечислены в [PHOTO_CREDITS.md](PHOTO_CREDITS.md).
- Первый запуск с Microsoft, Ely.by и локальным профилем, выбором оформления и созданием сборки.
- Для Microsoft-профиля предложение установить Bedrock через официальный сайт Minecraft. Luma не устанавливает Bedrock сам и не определяет право владения ею.
- Ссылки на Feed The Beast, Planet Minecraft и Vanilla Tweaks. Автоматический каталог и установка модов внутри Luma по-прежнему работают для Modrinth и CurseForge; внешние сервисы открываются в браузере.
- Экспериментальная страница Horizon получает новейший релиз его официального лаунчера с GitHub. Загрузка Windows ZIP идёт через очередь Luma и сверяется с официальной SHA256SUMS. После распаковки Horizon устанавливается, готовит игровые файлы и обновляется своим собственным лаунчером; интегрированного запуска в Luma пока нет.

## Выпуск следующей версии

В `.github/workflows/release.yml` настроена сборка на Windows и публикация релиза через `GITHUB_TOKEN`. Для нового выпуска измените версию в package.json, затем отправьте коммит с `[release]` в сообщении на `main` либо соответствующий тег `vX.Y.Z`. Workflow запускает тесты, создаёт Setup и публикует EXE, blockmap и latest.yml. Для локальной сборки выполните `npm ci`, `./scripts/installer-art.ps1`, `npm test`, `npm run setup`.

Проверено локально: TypeScript, сборка интерфейса, 23 автоматических теста, мастер первого запуска, сохранение языка Minecraft и разбор LAN-анонсов. Настоящее соединение между двумя отдельными компьютерами зависит от локальной сети и брандмауэра и не воспроизводилось в автоматическом тесте. Microsoft/Ely.by вход требует учётных данных пользователя и не проверялся.
