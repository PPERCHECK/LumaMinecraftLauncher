# Luma 1.0.0 — предварительная сборка

Это тестовый pre-release Windows x64. В нём проверяются первые локальные улучшения библиотеки. Полный список идей для 1.0.0 ещё не реализован.

## Установка

Запустите `Luma-Setup-1.0.0.exe`. Установщик не подписан сертификатом издателя Windows, поэтому SmartScreen может показать предупреждение. Установка поверх предыдущей версии сохраняет данные в `%APPDATA%\Luma Launcher`.

## Что вошло в эту сборку

- Из лаунчера удалены список друзей, добавление друзей, поиск LAN-миров и автоматический запуск мира по LAN. Подключение к серверам по адресу остаётся; LAN открывается из самой игры.
- К сборке можно добавить заметки и теги.
- Сборки можно помечать избранными, фильтровать по избранному и копировать для экспериментов.
- Добавлены казахский и белорусский варианты интерфейса (перевод пока частичный).
- Сохранена кнопка добровольной поддержки Boosty.

## Пока не вошло

Другие согласованные идеи — новые каталоги с прямой установкой, вход по QR, Minecraft-мод косметики с автоустановкой, реклама, онлайн-сервис друзей и статусов, расширенная диагностика, офлайн-проверки, резервирование снимков и прочее — ещё не реализованы полностью. Firebase не подключён. Эта сборка не должна считаться завершённой реализацией полного плана.

При обнаружении проблемы приложите диагностические логи и точную версию Minecraft/загрузчика. Не публикуйте OAuth-токены и личные данные.
